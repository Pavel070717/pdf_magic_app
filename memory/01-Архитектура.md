# Архитектура PDF Magic App

## Паттерн приложения

Приложение построено по паттерну **Flask Blueprint** — каждый модуль функциональности зарегистрирован как отдельный Blueprint со своим префиксом API.

**Поток данных**:
```
Браузер → Flask routes → utils (бизнес-логика) → state.json / SQLite / ФС
```

## Хранилища данных

### state.json — JSON-хранилище

```json
{
  "version": "1.0",
  "app_dir": "C:\\Users\\User\\Desktop",
  "files": [...],
  "replace_rules": [...],
  "accompanying_prefixes": [...],
  "registry_data": {...},
  "registry_dicts": {...},
  "created_directories": [...],
  "last_magic_run": {...}
}
```

Потокобезопасная запись через `utils/state.py` (write-to-temp-then-rename + fsync).

### data/materials.db — SQLite

4 таблицы: `materials`, `conversions`, `objects`, `requisites`. WAL-режим для параллельного чтения.

## Поток основных операций

### Копирование файлов (magic)

```
1. Пользователь загружает файлы (routes/files.py → temp_uploads/)
2. Настраивает правила замены (routes/rules.py → state.json)
3. Нажимает "Пуск" → routes/magic.py:
   a. Читает файлы из state
   b. Применяет правила замены к именам
   c. Нумерует: 01.Имя.ext
   d. Копирует в целевую директорию
   e. Генерирует Excel-реестр (utils/excel_registry.py)
```

### Генерация АОСР

```
1. Пользователь заполняет форму (routes/requisites.py → БД)
2. Нажимает "Сгенерировать" → routes/aocr.py:
   a. Копирует шаблон templates/AOCR_template.xlsx
   b. Заполняет через openpyxl
   c. Сохраняет в целевую директорию
   d. Опционально экспортирует PDF (win32com)
```

## Потокобезопасность

- `utils/state.py` — threading.Lock для JSON-операций
- `routes/core.py` — `_magic_lock` для прогресса магии
- `routes/converter.py` — `_jobs_lock` для задач конвертации
- SQLite — WAL-режим

## Безопасность

- Проверка path traversal (пути только на рабочем столе)
- Валидация MIME-типов при загрузке файлов
- `send2trash` вместо `os.remove` для удаления
- CORS ограничен localhost
- SECRET_KEY из env или random
