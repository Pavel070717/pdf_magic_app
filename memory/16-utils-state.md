# utils/state.py — Атомарная работа с JSON

**Путь**: `utils/state.py` (70 строк)

## Что делает

Потокобезопасная атомарная работа с `state.json`.

## Ключевые функции

### load_state() → dict

Чтение JSON с блокировкой. При ошибке возвращает дефолт:

```json
{
  "version": "1.0",
  "files": [],
  "last_magic_run": null
}
```

### save_state(state)

Сохранение с блокировкой и атомарной записью.

### _atomic_save(state)

Паттерн **write-to-temp-then-rename**:

1. `tempfile.mkstemp()` — создаёт временный файл
2. `json.dump()` — записывает JSON
3. `fsync()` — гарантирует запись на диск
4. `Path.replace()` — атомарная замена (на NTFS это rename)

При ошибке временный файл удаляется.

## Зачем это нужно

- Защита от повреждения `state.json` при сбоях (перезапись питания, crash)
- Потокобезопасность (многопоточные операции)
- Чтение/запись без гонок данных

## Зависимости

- `json`, `threading`, `tempfile`, `pathlib.Path`
