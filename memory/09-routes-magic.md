# routes/magic.py — Копирование и нумерация

**Путь**: `routes/magic.py` (310 строк)

## Что делает

Основная "магия" приложения — копирование файлов с нумерацией и генерация Excel-реестра.

## Эндпоинты

| Путь | Метод | Описание |
|---|---|---|
| `/api/magic/start` | POST | Запуск копирования |
| `/api/magic/cancel` | POST | Отмена операции |
| `/api/magic/progress` | GET | Текущий прогресс |
| `/api/magic/result` | GET | Результат последнего запуска |

## Поток копирования

1. Читает файлы из `state["files"]`
2. Для каждого файла:
   - Имя берётся из `file_info["name"]` (ИСХОДНОЕ имя), а не из temp-копии — суффикс `_1`/`_2`, который добавляется при повторе загрузки того же документа (routes/files.py), в итоговую папку и реестр НЕ попадает; одинаковые документы в итоге различаются только порядковым номером (01.), (02.)
   - Убирает старый порядковый номер `NN.` (см. `strip_leading_number`)
   - **Правила замены к физическому имени НЕ применяются** — файлы в итоговой папке сохраняют исходные (сокращённые) имена; правила раскрываются только в реестре (`normalize_name` в `parse_filename` utils/excel_registry.py)
   - Генерирует нумерованное имя: `01.Имя.ext`
   - Копирует через `shutil.copy2`
3. После копирования всех файлов:
   - Генерирует Excel-реестр (`generate_excel_registry`)
   - Сохраняет `last_magic_run` в state

## Формат нумерации

```
01.Документ.pdf
02.Сертификат (копия).pdf
03.Паспорт материалов.pdf
```

## Нумерация (актуальная логика)

- `strip_leading_number(name)` — убирает старый порядковый номер (`01.Акт.pdf → Акт.pdf`), чтобы на выходе оставался только новый сквозной номер
- `can_share_number(ext1, ext2)` — PDF и Excel (АОСР) с одинаковым наименованием получают один порядковый номер
- Сквозной счётчик хранится в `numbered_base` внутри `copy_files_worker`
- `generate_numbered_filename(start_number, name, ext)` — формат `NN.Имя.ext` (zfill(2))

## Проверки

- Не запускается если в целевой директории уже есть пронумерованные файлы
- Отмена через `cancelled` флаг в `magic_progress`
- Целевая директория должна существовать
