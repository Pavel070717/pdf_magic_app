# routes/materials.py — База материалов

**Путь**: `routes/materials.py` (177 строк)

## Что делает

CRUD для базы материалов (техническая документация с PDF-файлами).

## Эндпоинты

| Путь | Метод | Описание |
|---|---|---|
| `/api/materials` | GET | Список всех материалов |
| `/api/materials/add` | POST | Добавление материала |
| `/api/materials/pdf/<id>` | GET | Просмотр PDF |
| `/api/materials/<id>` | DELETE | Удаление материала |

## Формат файла материала

```
Док;Материал;Номер;Дата.pdf
```

Пример: `Сертификат;Бетон;БТ-001;15.03.2024.pdf`

## Хранение

PDF-файлы сохраняются в `~/Desktop/база материалов/`.

## Поведение

- Файлы с потерянными PDF автоматически удаляются из БД
- Поиск по полям: `doc_name`, `material_name`, `number`, `producer`
- Проверка path traversal при просмотре/удалении

## Зависимости

- `routes.core` (MATERIALS_DIR)
- `utils.database` (CRUD операции)
