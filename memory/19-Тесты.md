## Фикстуры (conftest.py)

- `clean_state` — очищает state.json перед каждым тестом
- `temp_db` — временная SQLite база
- `temp_db_all` — все 3 таблицы
- `app_client` — Flask test client
- `temp_dir` — временная директория

## Как запускать

```bash
pytest tests/                                    # Все тесты
pytest tests/ -v                                 # Подробный вывод
pytest tests/test_core.py                        # Конкретный файл
pytest tests/ -k "test_sanitize"                 # По имени
pytest tests/ --cov=. --cov-report=term          # С покрытием
```
