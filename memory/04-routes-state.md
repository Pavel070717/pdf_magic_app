# routes/state.py — Очистка состояния

**Путь**: `routes/state.py` (46 строк)

## Что делает

Blueprint `state_bp` с одним эндпоинтом для полной очистки состояния приложения.

## Эндпоинты

| Путь | Метод | Описание |
|---|---|---|
| `/api/state/clear` | POST | Полная очистка состояния |

## Поведение

При очистке **сохраняются**:
- `version`
- `app_dir`
- `created_directories` (созданные директории)

**Удаляется**:
- `files` (загруженные файлы)
- `replace_rules` (правила замены)
- `accompanying_prefixes` (префиксы сопровождающих)
- `registry_data` (данные реестра)
- `registry_dicts` (словари автодополнения)
- `registry_history` (история)

Также физически удаляется папка `temp_uploads/`.

## Зачем это нужно

Сброс приложения к начальному состоянию без удаления созданных директорий на рабочем столе.
