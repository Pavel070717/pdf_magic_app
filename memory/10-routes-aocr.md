# routes/aocr.py — Генерация АОСР

**Путь**: `routes/aocr.py` (290 строк)

## Что делает

Генерация формы АОСР (Акт освидетельствования скрытых работ) — заполнение Excel-шаблона + опциональный экспорт в PDF.

## Эндпоинты

| Путь | Метод | Описание |
|---|---|---|
| `/api/aocr/generate` | POST | Генерация .xlsx и .pdf |

## Шаблон

Файл `templates/AOCR_template.xlsx` — стандартный бланк АОСР с двумя листами:

### Лист "1" (18 полей)
- Наименование объекта
- Наименование застройщика
- Номер акта
- Дата
- Адрес объекта
- И т.д.

### Лист "2" (27 полей)
- Наименование работ
- Даты начала/конца
- Нормативные документы
- Представители сторон
- И т.д.

## Поведение

1. Копирует шаблон в целевую директорию
2. Заполняет через `openpyxl`
3. Сохраняет как `АОСР_номер_дата.xlsx`
4. Опционально экспортирует PDF через `win32com.client` (COM-автоматизация Excel)

## Экспорт PDF

Используется `win32com.client` для автоматизации Excel:
- Инициализирует COM
- Открывает Excel
- Экспортирует в PDF
- Корректно очищает ресурсы (COM objects)

**Примечание**: Экспорт PDF работает только если Microsoft Excel установлен.

## Зависимости

- `openpyxl` (чтение/запись Excel)
- `win32com.client` (экспорт PDF, опционально)
- `routes.core` (APP_DIR, logger)
- `utils.state` (load_state)
