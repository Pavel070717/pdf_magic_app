# routes/files.py — Управление файлами

**Путь**: `routes/files.py` (199 строк)

## Что делает

Загрузка, удаление и реорганизация файлов для обработки.

## Эндпоинты

| Путь | Метод | Описание |
|---|---|---|
| `/api/files` | GET | Список файлов с порядком |
| `/api/files/add` | POST | Загрузка файлов (multipart) |
| `/api/files/add-from-dir` | POST | Импорт всей папки с диска (рекурсивно) |
| `/api/files/remove` | POST | Удаление файла |
| `/api/files/reorder` | POST | Переупорядочивание |

## Допустимые расширения

`.pdf`, `.jpg`, `.jpeg`, `.png`, `.doc`, `.docx`, `.xls`, `.xlsx`, `.dwg`, `.dxf`

## Поведение

- Файлы сохраняются в `temp_uploads/`
- Проверяется расширение и MIME-тип
- Дублирующиеся имена получают суффикс `_1`, `_2` и т.д.
- Каждому файлу присваивается UUID
- При удалении физический файл удаляется с диска

## Импорт папки (`/api/files/add-from-dir`)

- Тело JSON: `{"path": "C:\\..."}` — путь к папке на диске
- Сканируется рекурсивно: внутри каждой папки сначала файлы, затем подпапки (естественная сортировка `natsort` по имени)
- Допустимые расширения фильтруются (`ALLOWED_EXTENSIONS`), остальные попадают в `rejected`
- Файлы копируются в `temp_uploads/` (исходники не изменяются и не удаляются)
- Порядок в `state["files"]` = порядок имён в папке → нумерация при магии идёт по порядку (`01.`, `02.`, …)
- Ответ: `{success, added, files, rejected}`

## Формат ответа

```json
{
  "files": [
    {
      "id": "uuid",
      "name": "filename.pdf",
      "display_order": 0
    }
  ]
}
```
