## Известные ограничения

1. **Экспорт PDF в АОСР** — работает только с Microsoft Excel (win32com)
2. **Конвертер PDF** — требует Java (OpenDataLoader)
3. **Платформа** — Windows (используются Windows-специфичные вызовы)
4. **app.py** — покрытие 50% (main() и kill_port сложно тестировать)
5. **reset_project.py** — 0% (admin utility, не тестируется)

### Основные
- Flask, flask-cors

- python-dotenv
- openpyxl, pypdf

### Dev
- pytest, pytest-cov

## Как запускать

```bash
python run.py              # Проверка зависимостей + запуск
python app.py              # Напрямую
pytest tests/              # Тесты
graphify update .          # Обновить граф
```
