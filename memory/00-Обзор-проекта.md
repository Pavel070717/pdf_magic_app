# PDF Magic App — Обзор проекта

## Что это за проект

PDF Magic App — это десктопное веб-приложение для работы с исполнительной документацией в строительстве. Приложение помогает строительным инженерам и прорабам автоматизировать рутинные задачи: копирование и нумерацию файлов, генерацию реестров, конвертацию PDF, заполнение форм АОСР.

**Технологии**: Python 3.10+, Flask, SQLite, Jinja2, Waitress (production server), openpyxl (Excel), pypdf.

**Платформа**: Windows (используется win32com для экспорта в PDF, send2trash для безопасного удаления).

## Ключевые возможности

1. **Копирование и нумерация файлов** — берёт файлы из временной папки, применяет правила замены имён, нумерует (`01.Имя.ext`) и копирует в целевую директорию на рабочем столе
2. **Генерация Excel-реестра** — создаёт полноценный Excel-документ с шапкой, таблицей файлов и блоками подписей (Сдал/Проверил/Принял)
3. **Конвертация PDF** — конвертирует PDF в markdown/json/html/text через Java CLI (OpenDataLoader)
4. **Генерация АОСР** — заполняет Excel-шаблон акта освидетельствования скрытых работ + экспорт в PDF через COM
5. **База материалов** — каталог технической документации с PDF-файлами (сертификаты, паспорта и т.д.)
6. **Управление директориями** — создание папок проектов на рабочем столе по датам
7. **Правила замены** — настраиваемые текстовые и символьные замены в именах файлов
8. **Реквизиты объектов** — хранение реквизитов строительных объектов для автозаполнения АОСР
9. **Импорт всей папки** — `POST /api/files/add-from-dir`: рекурсивная загрузка файлов из папки на диске в естественном порядке имён (natsort), исходники не изменяются

## Как запускать

```bash
python run.py          # Проверит зависимости, запустит сервер
# или
python app.py          # Напрямую (если зависимости установлены)
```

Сервер запускается на `http://localhost:5000`, автоматически открывает браузер.

## Хранилище данных

- **state.json** — JSON-файл: файлы, правила замены, данные реестра, созданные директории
- **data/materials.db** — SQLite: материалы, история конвертаций, объекты и реквизиты
- **~/Desktop/** — рабочие директории проектов (`DD.MM.YYYY/шифр_проекта/`)
- **~/Desktop/база материалов/** — PDF-файлы материалов

## Тестирование

```bash
pytest tests/                          # Все тесты
pytest tests/ --cov=. --cov-report=term  # С покрытием
```
