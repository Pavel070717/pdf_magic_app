# utils/excel_registry.py — Генерация Excel-реестра

**Путь**: `utils/excel_registry.py` (628 строк)

## Что делает

Создаёт полноценный Excel-документ реестра исполнительной документации с шапкой, таблицей и блоками подписей.

## Стили

- Шрифты: Times New Roman, размеры 10/12/14
- Заливка: голубая `#C2F8FC` (для строк АОСР)
- Границы: тонкие, сплошные
- Печать: A4, масштаб 67%, поля 1.5см

## Структура документа

### Шапка (строки 1-28)
- Название организации
- Объект
- Застройщик
- СК
- Генподрядчик
- Исполнитель
- Номер реестра

### Таблица (строки 29+)

| Столбец | Содержимое |
|---|---|
| А | № п/п |
| Б | Наименование файла |
| В | № документа |
| Г | Дата |
| Д | Кол-во страниц |
| Е | Стр. по списку |
| Ж | Гиперссылка |
| З | Комментарий |

**Гиперссылка (колонка Ж)**: относительная формула `=HYPERLINK("<имя файла>","<имя файла>")`. Адрес — путь от папки реестра (файлы лежат рядом), поэтому ссылки работают при переносе папки целиком. Формула используется с английским именем функции и запятой-разделителем — это открывается в Excel без «лечения» файла; русский Excel показывает как ГИПЕРССЫЛКА.

### Подписи (после таблицы)

3 блока:
1. **Сдал** — Подрядчик (должность, подпись, расшифровка, дата)
2. **Проверил** — Технадзор (должность, подпись, расшифровка, дата)
3. **Принял** — Заказчик (должность, подпись, расшифровка, дата)

## Ключевые функции

- `generate_excel_registry(folder_path, registry_data, saved_dicts, filter_names)` → Path — главная функция
- `collect_files(folder_path, filter_names)` → list — сбор файлов с natsort
- `parse_filename(filename)` → dict — парсинг `Название;Номер;Дата;Описание.ext`
- `fill_rows(ws, rows, folder_path)` → int — заполнение строк
- `build_signatures(ws, registry_data, last_row)` → int — блоки подписей
- `fix_page_margins_in_xlsx(xlsx_path)` — исправление полей через zipfile

## Формат имени файла

```
Название;Номер;Дата;Описание.ext
```

Пример: `Сертификат;БТ-001;15.03.2024;Описание.pdf`

## Зависимости

- `openpyxl` (создание Excel)
- `natsort` (натуральная сортировка)
- `pypdf` (чтение страниц PDF)
- `zipfile`, `xml.etree.ElementTree` (редактирование XML в xlsx)
