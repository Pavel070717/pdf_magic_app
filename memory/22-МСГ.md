# МСГ — месячно-суточный график (routes/msg.py, utils/msg_db.py, templates/msg.html)

## Назначение
Страница `/msg` (пункт меню «МСГ») для ведения Общего журнала работ (ОЖР)
и просмотра месячно-суточного графика — «шахматка»: строки работ, колонки
дней месяца, в клетках — объём выполненной работы.

## Хранение
SQLite `data/msg.db`, таблица `ozh_items`:
`id, date ('YYYY-MM-DD'), work_name, position, unit, volume, created_at`.

## Вкладка «Общий журнал работ»
- Дата (input date) + динамические строки: Наименование работ / Позиция / Ед. изм. / Объём (+ «＋ Добавить работу», удаление ✕)
- `POST /api/msg/ozh/items` `{date, items:[{work_name, position, unit, volume}]}` — сохраняет за один день; пустые `work_name` пропускаются, без единой работы → 400
- `GET /api/msg/ozh/items?date=YYYY-MM-DD` — записи за день (по id ASC)
- `DELETE /api/msg/ozh/items/<id>` — удаление записи
- Таблица записей журнала с кнопками удаления

## Вкладка «МСГ — просмотр»
- `GET /api/msg/months` — список месяцев (из БД + текущий), с меткой `has_data`
- `GET /api/msg/month?month=YYYY-MM` — данные для шахматки: `label`, `days_in_month`, `weekends` (номера дней), `today`, `rows`, `day_totals`, `grand_total`
- Номера дней в JSON — СТРОКИ (`"15"`), потому что ключи dict → JSON: в JS и в тестах обращаться `days["15"]` / `dayTotals["15"]`

## Ключевое правило агрегации (в utils/msg_db.get_month_rows)
- Группировка по ключу `(work_name, position, unit)` — 100% идентичность
- При совпадении ключа объёмы СУММИРУЮТСЯ по своим дням
- При несовпадении (другая ед. изм., позиция или имя) — НОВАЯ строка
- Порядок строк — как впервые встретилось в ОЖР (ORDER BY id)

## Дизайн-детали (внутренние CSS в msg.html)
- Липкие колонки: `msg-fix` (наименование, left:0, 210px с ellipsis), `msg-fix-2` (позиция, left:210px, 90px), `msg-fix-3` (ед. изм., left:300px, 80px); header sticky top
- Выходные — подложка warning; сегодняшний день — рамка accent; ячейка с объёмом — тепловая заливка `rgba(79,143,255, alpha)` пропорционально max объёму, «·» — ноль
- Строка «Итог за месяц»: дневные суммы + гранд-итог, колонка «Итог» справа
- Месяц-селектор ‹ › с дропдауном «Месяц •» (• = есть данные)
